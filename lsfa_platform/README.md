# المنصة الوطنية الرقمية للهيئة اللبنانية لسلامة الغذاء (LSFA)

حزمة برمجية متكاملة مبنية على **Python / Django / Django REST Framework / PostgreSQL** تغطي الوحدات الأساسية للمنصة وفق أحكام قانون سلامة الغذاء اللبناني رقم 35/2015:

1. **السجل الوطني للمؤسسات الغذائية** وتصنيف المخاطر.
2. **التفتيش والرقابة والاستمارات القطاعية السبع** وحساب درجة الامتثال والخطورة تلقائياً.
3. **المخالفات والإجراءات التصحيحية (CAPA)** والإحالات القانونية.
4. **المختبرات والعينات وسلسلة الحيازة (Chain of Custody)**.
5. **التتبع الغذائي والدفعات التشغيلية والاستدعاء (Recall)**.
6. **الشكاوى والبلاغات وبوابة المواطنين والتنبيهات العامة**.
7. **المراسلات والأرشفة والحوكمة**.
8. **سجل التدقيق الإلكتروني غير القابل للتعديل (Immutable Audit Log)** وإدارة الصلاحيات.
9. **واجهة بوابة عامة ولوحة مؤشرات وطنية** جاهزة للعرض والاختبار.

## طريقة التشغيل السريع

### الخيار أ: التشغيل المباشر على جهازك (VS Code + PostgreSQL)
1. أنشئ قاعدة بيانات في PostgreSQL باسم `lsfa_db`.
2. انسخ `.env.example` إلى `.env` وضع بيانات اتصال PostgreSQL.
3. أنشئ بيئة افتراضية وثبّت المتطلبات:
   ```bash
   python -m venv venv
   source venv/bin/activate  # أو venv\Scripts\activate على ويندوز
   pip install -r requirements.txt
   ```
4. أنشئ الجداول وحساب المدير وشغّل الخادم:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   python manage.py createsuperuser
   python manage.py runserver
   ```
5. افتح الروابط التالية في المتصفح:
   - الواجهة الرئيسية وبوابة المواطنين: `http://127.0.0.1:8000/`
   - لوحة الإدارة والرقابة المركزية: `http://127.0.0.1:8000/admin/`
   - واجهة البيانات البرمجية (API): `http://127.0.0.1:8000/api/`

### الخيار ب: التشغيل عبر Docker
```bash
docker compose up --build
```
